# 🚀 InsightFlow AI

## Enterprise Data Insight & Quality Platform

InsightFlow AI is an enterprise-level Data Science application that helps users clean, analyze and visualize datasets automatically.

---

# Features

- User Authentication
- CSV / Excel Upload
- Data Profiling
- Data Cleaning
- Missing Value Detection
- Duplicate Detection
- Data Quality Score
- Automatic Analysis
- Interactive Charts
- Business Insights
- PDF Report
- CSV Export
- Excel Export

---

# Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-Learn
- SQLite
- ReportLab
