## Enterprise Data Insight & Quality Platform

---

## Features

- User Authentication
- CSV / Excel Upload
- Data Profiling
- Data Cleaning
- Missing Value Detection
- Duplicate Detection
- Data Quality Score
- Automatic Analysis
- Interactive Charts
- Business Insights
- PDF Report Generation
- CSV Export
- Excel Export

- Python
- Streamlit
- Pandas
- NumPy

- SQLite
- ReportLab

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Vaibhavbhojane26/InsightFlow-AI.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
